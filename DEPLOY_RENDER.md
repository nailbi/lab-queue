# Деплой на Render

Render запускает PHP-приложения через Docker. В проекте уже есть `Dockerfile`,
который ставит зависимости, создаёт базу SQLite, прогоняет миграции и сидер,
и поднимает сервер.

## Перед деплоем (один раз, локально)

Эти файлы — только код приложения. Сначала соберите полный Laravel-проект
(см. README.md), убедитесь, что он работает локально, и положите рядом
`Dockerfile` из этого архива. Затем залейте всё в репозиторий на GitHub.

```bash
git init
git add .
git commit -m "Курсовой: очередь на сдачу лаб"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/lab-queue.git
git push -u origin main
```

## Шаги на Render

1. Зарегистрируйтесь на https://render.com и привяжите аккаунт GitHub.
2. Нажмите **New → Web Service**.
3. Выберите ваш репозиторий `lab-queue`.
4. Настройки:
   - **Language / Runtime:** Docker (Render сам увидит `Dockerfile`);
   - **Region:** ближайший (например, Frankfurt);
   - **Instance Type:** Free (для курсового хватит).
5. В разделе **Environment** добавьте переменные окружения:

   | Ключ            | Значение                                  |
   |-----------------|-------------------------------------------|
   | `APP_KEY`       | результат `php artisan key:generate --show` (запустите локально и скопируйте, начинается с `base64:`) |
   | `APP_ENV`       | `production`                              |
   | `APP_DEBUG`     | `false`                                   |
   | `DB_CONNECTION` | `sqlite`                                  |

6. Нажмите **Create Web Service**. Render соберёт образ и запустит приложение.
7. После сборки сайт будет доступен по адресу вида
   `https://lab-queue-xxxx.onrender.com`.

## Важные замечания

- **Бесплатный план «засыпает».** После 15 минут без запросов сервис
  останавливается, и первый следующий запрос грузится ~30 секунд. Для защиты
  курсового это нормально — просто откройте сайт заранее.
- **SQLite на бесплатном плане не сохраняется между деплоями** (файловая
  система эфемерная). База пересоздаётся сидером при каждом запуске. Для
  курсового демо это ок. Если нужно постоянное хранилище — подключите
  бесплатную PostgreSQL на Render и поменяйте `DB_CONNECTION` на `pgsql`
  с соответствующими переменными (Render выдаёт их в разделе базы).
- **Логотип:** положите файл в `public/images/logo.png` до пуша в GitHub,
  иначе в шапке он просто не отобразится (место под него уже готово).

## Как обновлять сайт

Любой `git push` в ветку `main` автоматически пересобирает и перезапускает
сервис на Render — отдельных действий не нужно.
