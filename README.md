# Очередь на сдачу лабораторных работ (Laravel)

Курсовой проект: веб-сайт для электронной очереди на защиту лабораторных работ.

## Что умеет

**Студент (без регистрации):**
- выбирает предмет;
- вводит своё имя, названия лабораторных и их количество;
- встаёт в очередь и видит её в реальном времени (автообновление);
- может выйти из очереди.

**Староста (вход по паролю):**
- создаёт / редактирует / удаляет предметы;
- задаёт и меняет количество лабораторных по предмету;
- регулирует очередь (двигает записи вверх/вниз, удаляет);
- отмечает явку: «Пришёл», «Сдал», «Не явился».

## Как развернуть

Эти файлы — содержимое приложения. Их нужно положить поверх свежего Laravel-проекта,
потому что папки `vendor/`, `artisan`, `composer.json` и т.п. ставятся Composer'ом.

### Вариант А. Новый проект + копирование файлов

```bash
# 1. Создать чистый Laravel-проект
composer create-project laravel/laravel lab-queue-app
cd lab-queue-app

# 2. Поставить стартовый набор авторизации (даёт страницы входа/регистрации и routes/auth.php)
composer require laravel/breeze --dev
php artisan breeze:install blade

# 3. Скопировать файлы из этого архива поверх проекта:
#    app/Models/*            -> app/Models/
#    app/Http/Controllers/*  -> app/Http/Controllers/
#    database/migrations/*   -> database/migrations/   (можно заменить дефолтные)
#    database/seeders/*      -> database/seeders/
#    resources/views/*       -> resources/views/
#    routes/web.php          -> routes/web.php

# 4. Настроить БД в .env (проще всего SQLite):
#    DB_CONNECTION=sqlite  + создать файл database/database.sqlite
touch database/database.sqlite

# 5. Применить миграции и создать старосту + демо-данные
php artisan migrate:fresh --seed

# 6. Запустить
php artisan serve
```

Открыть http://127.0.0.1:8000

### Вход старосты

- адрес: `/login`
- логин: `starosta@example.com`
- пароль: `password`  (обязательно смените!)

## Структура (соответствие шаблону записки)

| Раздел записки            | Где в проекте                                   |
|---------------------------|-------------------------------------------------|
| Проектирование БД (2.1)   | `database/migrations/`                          |
| Главная страница (2.3)    | `resources/views/home.blade.php`                |
| Детальная страница (2.4)  | `resources/views/subject.blade.php`             |
| Административная часть     | `resources/views/admin/`, `Admin/*Controller`   |
| Динамический элемент      | AJAX-автообновление в `subject.blade.php`        |
| Расчёт по параметрам      | позиция в очереди, счётчики записавшихся         |
| Статьи                    | описание предмета на детальной странице          |

## Сущности БД

- `subjects` — предметы (название, описание, кол-во лаб);
- `queue_entries` — записи в очереди (имя, названия лаб, кол-во, позиция, статус);
- `users` — учётная запись старосты для входа.
